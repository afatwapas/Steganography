This project implements image steganography — the art of hiding secret messages inside digital images — using the Least Significant Bit (LSB) technique.
It allows users to embed a secret text message inside an image and later extract it securely without noticeable visual changes.

Features

🔒 Embed and Extract Messages: Hide secret text within .png images and retrieve it easily.
⚡ Fast NumPy-based Implementation: Efficient pixel manipulation using vectorized operations.
🧹 Auto-clears previous data: Old hidden data bits are cleared before re-embedding to ensure clean encoding.


Tech Stack- Python , Numpy ,PIL
